# Предварительная загрузка метаданных

Импорт архива и получение внешних сведений — разные задачи. История разбирается в браузере, после чего библиотека доступна пользователю. Обложки и жанры запрашиваются по мере показа карточек; полное аудио — перед воспроизведением. Проверка аудитории исполнителей работает отдельной фоновой очередью. Полного предварительного обхода всех треков в текущей версии нет.

## От чего зависит время

Внешним API нужны отдельные запросы по трекам, альбомам и исполнителям. Скорость зависит от числа уникальных сущностей, задержек поставщиков, попаданий в кеш, повторов и ограничений частоты. Увеличение числа клиентских воркеров не отменяет квоты внешних источников.

Пример нижней оценки для **условной библиотеки из 10 000 треков**, если каждому нужен один запрос к одному поставщику:

| Интервал запросов | Минимальное время очереди |
| --- | ---: |
| 180 мс | 30 минут |
| 220 мс | около 37 минут |
| 1 050 мс | около 2 часов 55 минут |
| 3 100 мс | около 8 часов 37 минут |

Это арифметические примеры, а не измерение покрытия или обещание времени импорта. Реальная работа может требовать нескольких запросов на трек, а общие альбомы и исполнители, напротив, сокращают их число. Параллельные очереди разных поставщиков не следует просто суммировать.

Интервалы в реализации являются настройками приложения, а не гарантированными квотами сервисов. [MusicBrainz](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting) ограничивает частоту обращений с одного IP. Для Apple действует собственное [ограничение Search API](https://performance-partners.apple.com/search-api). Ошибки ограничения частоты требуют паузы и соблюдения `Retry-After`.

## Что потребуется для полного обхода

Полная подготовка большой библиотеки потребует возобновляемой очереди с приоритетом видимых карточек и воспроизведения, дедупликацией и сохранением небольших метаданных с учётом условий поставщиков. Текущий серверный RAM-кеш ограничен по времени и размеру и не является постоянным общим каталогом. После перезапуска сервера его содержимое исчезает.

Сохранять следует только разрешённые метаданные, происхождение, время проверки и внешние ссылки. Предварительное получение всех аудиоссылок мало полезно: они могут истекать до воспроизведения. Файлы обложек и музыки для такой подготовки не нужны.

Количество завершённых проверок не равно полноте данных. Неизвестные жанры, отсутствующие записи и пробелы в исторических снимках аудитории могут остаться после любого полного прохода. Недоступные значения не оцениваются и не подменяются статистикой другого сервиса.
