# Источники аудио

Единый HTML Audio плеер остаётся в App независимо от открытой карточки. Закрытие карточки, поиск, фильтры и переключение разделов не размонтируют его. Повторный выбор того же трека переключает паузу; смена трека выбирает новый источник.

## Подключённые источники

| Источник | Формат | Доступ |
| --- | --- | --- |
| Audius | Полная открытая запись, когда найдено точное совпадение | Без ключа для используемых публичных read-only методов |
| Jamendo | Полная запись из независимого каталога | Адаптер готов; нужен `JAMENDO_CLIENT_ID` в `.env.local` |
| Deezer | Превью | Без ключа |
| Apple Music / iTunes | Превью | Без ключа, с ограничением частоты запросов |

Полная версия имеет приоритет перед превью. Наличие полного аудио не выводится из расширения URL или заявленной длительности: поставщик должен подтвердить доступный полный stream. Audius с gated, deleted, private/unlisted, blocked или недоступными записями исключается. Название и исполнитель должны совпасть после нормализации регистра и пунктуации; live/remix/cover не заменяют исходную версию. При неоднозначных аккаунтах артист не угадывается; в Audius предпочтителен подтверждённый аккаунт.

Если полный поток не найден или не воспроизводится, остаётся независимо найденное превью. Плеер показывает фактически выбранный формат, поставщика и ссылку на запись. Не все треки из архива Spotify присутствуют в каталогах Audius/Jamendo.

Поиск полного аудио выполняется только при нажатии «Слушать». Запрос `GET /api/tracks/:id?title=...&artist=...&full=true&details=false` не ждёт жанров MusicBrainz или жанров альбома Deezer. Поиск полных записей ограничен таймаутом, положительные и отрицательные результаты хранятся только в RAM. `GET /api/audio/providers` показывает реальные состояния источников: Jamendo без ключа имеет `configured:false`.

Медиа не сохраняются в файлы, IndexedDB или CacheStorage и не проксируются приложением: браузер читает HTTPS-поток поставщика. `/api/audio/:id` остаётся совместимым перенаправлением. Стандартный HTTP-кеш браузера контролируется браузером и внешним CDN.

## Проверка и ссылки

Автоматические тесты используют фиксированные ответы поставщиков и проверяют точность сопоставления, разрешённые URL, недоступные записи и выбор полного потока или превью. Они не доказывают наличие конкретного трека в каталоге на момент воспроизведения. Состояние `configured` сообщает о настройке адаптера, а не о текущей доступности поставщика.

- [Audius API](https://docs.audius.org/api/)
- [Jamendo tracks](https://developer.jamendo.com/v3.0/tracks): используется поток `audio`, а не `audiodownload`.
- [Deezer API](https://developers.deezer.com/api)
- [Apple Search API](https://performance-partners.apple.com/search-api)

Spotify Web API не предоставляет полные композиции в виде MP3. [Spotify Web Playback SDK](https://developer.spotify.com/documentation/web-playback-sdk/reference) требует отдельной интеграции с OAuth и подходящим аккаунтом; в текущий плеер он не подключён.
