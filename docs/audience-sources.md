# История слушателей

Основной бесплатный источник OG.Listener — таблицы месячных слушателей Kworb и их реальные снимки в Internet Archive. Ключ или платная подписка для этого способа не нужны.

## Источники и метрика

- [Kworb, Monthly Listeners](https://kworb.net/spotify/listeners.html) — текущие таблицы месячной аудитории Spotify.
- [Internet Archive](https://web.archive.org/) — сохранённые версии этих таблиц с фактической датой захвата.
- [Публичный CDX-индекс](https://web.archive.org/cdx/search/cdx?url=kworb.net/spotify/listeners.html&output=json&filter=statuscode:200&collapse=timestamp:6&limit=3) — поиск доступных захватов. Наличие индекса не гарантирует покрытие любого исполнителя или года.

У Kworb страницы `artist/..._songs.html` показывают **streams**, а не уникальных месячных слушателей. Они не используются для коэффициента раннего открытия. Надпись текущей таблицы «Statistics since March 1st 2023» относится к отображаемой статистике таблицы; реальные более ранние архивные захваты проверяются отдельно.

## Бесплатный адаптер

`GET /api/audience/providers` возвращает `kworb` первым, с `configured:true`, `paid:false`. Запрос:

```json
{
  "provider": "kworb",
  "artists": [{
    "name": "Coldplay",
    "artistId": "4gzpq5DPGxSnKTe4SA8HAU",
    "firstPlayed": "2024-01-15T00:00:00.000Z"
  }]
}
```

`POST /api/audience/resolve` — автоматический пакетный маршрут: от 1 до 100 исполнителей; клиент использует группы по 20 и сохраняет прогресс. Совместимый `POST /api/audience/import` принимает от 1 до 20 исполнителей. По умолчанию используется `kworb`. Результат: `snapshots`, `coverage`, `errors`, `summary`. Каждая точка содержит `artist`, `artistId`, `date`, `listeners`, `source:"Kworb"`, `metric:"monthly_listeners"`, `sourceUrl` и `archived`.

Адаптер сверяет Spotify artist ID; без ID требуется однозначное совпадение имени. Текущие даты берутся из `Last-Modified`, исторические — из фактического `Memento-Datetime` или реального URL архивного захвата. Если Wayback перенаправил запрос на более поздний снимок, запрошенная дата не подставляется вместо фактической.

Две текущие страницы рейтинга (всего 5 000 исполнителей) и два CDX-индекса разделяются между всеми пакетами библиотеки. Исполнитель вне текущего рейтинга получает статус `not_tracked`, без отдельных обходов Wayback. Это ограничение автоматического бесплатного поиска, а не утверждение об отсутствии любых исторических данных. Spotify artist ID предпочтительнее имени и помогает сопоставлять переименования.

CDX ограничен одной записью в месяц и 600 строками. Для найденных исполнителей выбираются подходящий исходный снимок и ранний/последний последующие снимки. Одна архивная таблица сразу обогащает всех известных исполнителей в пакете. На пакет разрешено не более 12 новых архивных запросов, одновременно не более трёх; дедлайн — 40 секунд, таймаут одного сетевого запроса — 8 секунд. При большом разбросе дат возвращается `deferred`; последующие пакеты используют уже полученные таблицы. Клиенту подходит таймаут 60 секунд. Отмена клиентского запроса прекращает запуск последующих архивных работ; уже начавшиеся общие сетевые чтения завершаются по своему короткому таймауту.

Успешные таблицы хранятся только в оперативной памяти с TTL 6 часов. Ошибки кешируются на 30 секунд, HTTP 429 — на минуту, поэтому автоматический обход библиотеки не повторяет один и тот же неудачный запрос для каждого артиста. `summary.providerUnavailable` означает недоступность обеих текущих таблиц; `summary.rateLimited` сигнализирует об ограничении частоты. Источник может вернуть HTTP 200 с частичными данными и `coverage.status:"unavailable"`, чтобы не терять реально полученные наблюдения.

Покрытие разреженное. Отсутствующие даты не интерполируются, streams/followers/popularity не заменяют listeners. `coverage.hasBaseline` истинно только для наблюдения не позднее первого прослушивания и не старше 31 дня. Возвращаются фактические `from`, `to`, `count`, `baselineDate`, `baselineAgeDays`, `warnings`, `status`, `retryable`, `retryAfterSeconds`, `errorCode`, `note`. Статусы: `ready`, `no_baseline`, `not_tracked`, `unavailable`, `deferred`, `ambiguous`. Недоступность архива может оставить только текущую точку; это не является историей с исходным значением.

Документация Internet Archive: [Wayback APIs](https://archive.org/help/wayback_api.php), [официальный CDX server](https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server). API доступен без ключа, но доступность отдельных захватов и отсутствие ограничений по частоте не гарантируются.

## График в карточке

В карточках треков и исполнителей история аудитории показана непрерывной линией с градиентной заливкой. Точки обозначают реальные снимки одного источника с метрикой `monthly_listeners`; значения Last.fm, streams и followers в эту серию не входят. Линия соединяет наблюдения, но не добавляет рассчитанные снимки и не выходит за границы доступных наблюдений. При одном снимке отображается только точка, при отсутствии снимков — статус автоматической проверки.

Вертикальная отметка показывает дату первого прослушивания выбранного трека или исполнителя. Эта дата входит в область графика даже до начала доступной истории; неизвестный участок остаётся пустым. Наведение, касание или стрелки на клавиатуре показывают дату и точное значение ближайшего реального снимка. Коэффициент раннего открытия по-прежнему требует исходного наблюдения не старше 31 дня для Kworb; линия между точками не используется в его расчёте.

## Обложки, жанры и аудио

`POST /api/catalog/resolve` принимает максимум 100 видимых треков, возвращает `{entries,errors}`. Это разрешение метаданных по запросу, без глобальной фоновой очереди. `details:false` получает обложку Spotify oEmbed; `details:true` дополнительно ищет точный трек в Deezer и жанры его альбома. `GET /api/tracks/:id?title=...&artist=...` также пробует Apple, если превью отсутствует. Нормализация допускает разный регистр и пунктуацию, но не заменяет трек концертной версией, кавером или другим артистом.

- [Deezer Search API](https://developers.deezer.com/api/search): живой запрос `Coldplay Yellow` вернул точный трек Yellow с remote preview на `cdnt-preview.dzcdn.net`, обложкой и портретом исполнителя. Жанр Rock получен из реального ответа [альбома Parachutes](https://api.deezer.com/album/301663).
- [Apple Search API](https://performance-partners.apple.com/search-api): бесплатный поиск примерно 20 запросов в минуту. Возвращает `primaryGenreName`, ссылки на обложки и доступные превью. Превью предназначены для потокового промо с атрибуцией и ссылкой на магазин; файлы не сохраняются приложением. Наличие превью для каждого трека не гарантируется.
- [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API): бесплатен для некоммерческого использования, без API-ключа. Если жанр отсутствует, используется однозначно найденный артист и его curated `genres`; произвольные теги вроде названий стран не выдаются за жанры. [Лимит](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting) — около одного запроса в секунду.
- [Last.fm track.getInfo](https://www.last.fm/api/show/track.getInfo) подключён как необязательный источник тегов: нужен серверный `LASTFM_API_KEY`, посетителям авторизация не требуется. Произвольные теги отделены от распознаваемых жанров. Статистика Last.fm не используется как история Spotify monthly listeners. [Подробнее](lastfm.md).

Сервер возвращает только проверенные HTTPS-ссылки поставщиков. Приложение не сохраняет медиа на диск или в IndexedDB/CacheStorage. Метаданные имеют TTL и хранятся в памяти процесса; после перезапуска исчезают. `/api/artwork/:id` и `/api/audio/:id` — HTTP 302 на удалённый CDN с `Cache-Control:no-store`, без проксирования или сохранения байтов. Браузер читает изображения и поток аудио непосредственно у поставщика; обычная обработка HTTP браузером и политика кеша внешнего CDN управляются браузером/поставщиком.

Spotify Web API [Get Artist](https://developer.spotify.com/documentation/web-api/reference/get-an-artist) не предоставляет временной ряд monthly listeners. Полные Spotify-композиции не являются выдаваемыми MP3 из Web API; [Web Playback SDK](https://developer.spotify.com/documentation/web-playback-sdk) требует авторизации и подходящего аккаунта. Нативный плеер OG.Listener предпочитает открытые полные записи Audius / настроенного Jamendo и использует Deezer/Apple previews как fallback. [Источники аудио](audio-sources.md).

## Дополнительный платный источник

Chartmetric — необязательный источник: `CHARTMETRIC_REFRESH_TOKEN` в `.env.local`, `provider:"chartmetric"`. Адаптер использует запрос [Artist Fan Metrics by Source](https://apidocs.chartmetric.com/reference/tag/artist/get/api/artist/id/stat/source) с `field=listeners`, `since`, `until`, `isDomainId=true`, `interpolated=false`. Токен остаётся на сервере. Доступ и глубина истории зависят от [тарифа API](https://chartmetric.com/plans/api); автоматические тесты используют фиксированные ответы, а не платный аккаунт.

Soundcharts и Songstats предлагают собственные API с учётной записью/тарифом; они не используются как якобы бесплатная замена. [Soundcharts Streaming Audience](https://developers.soundcharts.com/api/reference/artist/get-streaming-audience), [официальный Songstats API](https://github.com/Songstats/songstats-api).

## Проверки

Локальные тесты используют фиксированные ответы поставщиков. Проверяются старый/новый HTML Kworb, запрет stream-таблиц, фактические даты перенаправлений, отсутствие исходного снимка, частичное покрытие при недоступном архиве, TTL/in-flight дедупликация, строгая идентификация трека, remote redirects и отсутствие созданных медиа/метаданных на диске. Тесты не выполняют массовых сетевых запросов.
