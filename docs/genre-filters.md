# Как работают жанры и фильтры

Жанры автоматически берутся из метаданных; классификатора, который слушает аудио, здесь нет. Deezer даёт жанр альбома при точном совпадении названия и исполнителя. Настроенный Last.fm дополняет пользовательские теги трека: только известные музыкальные стили становятся жанрами, остальные остаются отдельными тегами. При отсутствии жанра запрашиваются curated genres исполнителя MusicBrainz, если имя сопоставлено однозначно. Apple/iTunes может дополнить основной жанр при поиске аудио. Поэтому тег иногда описывает альбом или исполнителя шире, чем конкретную композицию. Last.fm требует один серверный ключ приложения, вход посетителя не нужен.

Сведения запрашиваются по мере показа карточек и хранятся в памяти текущего приложения. Фильтр жанра работает по уже известным тегам. Неизвестный жанр означает как ещё не проверенный трек, так и отсутствие подходящих сведений у поставщика; это не отдельный музыкальный стиль. После выбора жанра скрытые неизвестные треки самостоятельно не попадают в очередь показа. Полный массовый обход всех песен не запускается: для большого архива он занял бы много времени и запросов.

В меню фильтров показано покрытие «Как определяются жанры · X из N» и пояснение этого ограничения. Показатель относится ко всему архиву, а не к текущей отфильтрованной выдаче. Список известных жанров дополняется при просмотре библиотеки. Обновлённые метаданные не сохраняются как медиакеш; после обновления страницы часть сведений запрашивается заново.

Порядок обработки: события в выбранном периоде и с выбранным порогом длительности → жанр → группировка исполнителей → минимальное/максимальное количество прослушиваний. Начальная и конечная даты включительны, время UTC. В режиме исполнителей при выбранном жанре считаются только соответствующие песни этого артиста, а не вся его дискография. График внутри карточки показывает всю слышимую историю трека или исполнителя независимо от фильтров библиотеки.

Метки сравниваются без учёта регистра, но без полного дерева стилей и общего объединения всех синонимов: `Trap`, `Hip-Hop/Rap`, `Rap/Hip Hop` могут быть отдельными пунктами. Для Last.fm используется небольшой консервативный словарь узнаваемых стилей. Аудио не загружается для определения жанра. [Правила Last.fm](lastfm.md).

Источники: [Deezer album API](https://developers.deezer.com/api/album), [MusicBrainz genres](https://musicbrainz.org/doc/Genre), [Apple Search API](https://performance-partners.apple.com/search-api).
